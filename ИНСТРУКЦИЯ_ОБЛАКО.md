# 🚀 Пошаговая инструкция: Запуск Лид-Парсера в Облаке 24/7 (Render / Railway)

Этот способ позволяет запустить веб-парсер на бесплатном облачном сервере с постоянным веб-адресом. Парсер будет доступен вам и вашему другу круглосуточно с любого устройства (компьютер, планшет, смартфон), даже когда ваш домашний ПК выключен.

---

## Вариант А: Развертывание на Render.com (Рекомендуется, 100% бесплатно)

Render предоставляет бесплатный хостинг Docker-сервисов с автоматическим выпуском SSL-сертификата (HTTPS).

### Шаг 1. Отправка кода на GitHub
1. Перейдите на [github.com/new](https://github.com/new) и создайте новый репозиторий:
   - **Repository name**: например `lead-parser`
   - Выберите **Public** или **Private** (на ваш выбор)
   - Галочки (Add a README file) ставить **не нужно**.
   - Нажмите зеленую кнопку **Create repository**.
2. Скопируйте ссылку на репозиторий (например: `https://github.com/ваш_логин/lead-parser.git`).
3. В папке с проектом дважды кликните по **`PUSH_TO_GITHUB.bat`**, вставьте скопированную ссылку и нажмите Enter. Код мгновенно загрузится на GitHub.

### Шаг 2. Запуск сервиса на Render
1. Зарегистрируйтесь или войдите на [render.com](https://render.com) (удобно войти через аккаунт GitHub).
2. В верхнем правом углу нажмите **New +** → выберите **Web Service**.
3. Выберите **Build and deploy from a Git repository** → подключите свой репозиторий `lead-parser`.
4. Render автоматически распознает файл `render.yaml` или `Dockerfile`:
   - **Name**: `lead-parser`
   - **Region**: Frankfurt (или любой европейский/американский)
   - **Instance Type**: **Free** ($0 / month)
5. Нажмите кнопку **Deploy Web Service** внизу страницы.
6. Через 2–3 минуты сборка завершится, и вы получите постоянную публичную ссылку вида:
   ```text
   https://lead-parser-xxxx.onrender.com
   ```
7. Отправьте эту ссылку другу — парсер готов к работе 24/7!

## Вариант Б: Развертывание на Railway.app (Альтернатива)

Railway — быстрый облачный провайдер, который разворачивает Docker-контейнеры без задержек.

1. Зарегистрируйтесь на [railway.app](https://railway.app) через GitHub.
2. Нажмите **New Project** → **Deploy from GitHub repo**.
3. Выберите репозиторий `lead-parser`.
4. Нажмите **Deploy Now**.
5. Во вкладке **Settings** → **Networking** нажмите **Generate Domain**.
6. Вы получите готовый HTTPS-адрес (например: `https://lead-parser-production.up.railway.app`).

## Что уже настроено в проекте:
- **`Dockerfile`**: Официальный образ Microsoft Playwright с предустановленным Chromium, настроенный для headless-сбора карт и бирж.
- **`render.yaml`**: Автоматический манифест для Render (порт 8080, авто-билд).
- **`railway.json`**: Манифест для быстрого развертывания на Railway.
- **`.dockerignore` и `.gitignore`**: Исключены тяжелые локальные папки (`venv`, базы, кэш), сборка в облаке длится минимальное время.
