# 🚀 Lead Hunter Pro: Парсер Яндекс Карт, 2ГИС, Google Maps & Бирж Фриланса

Ультимативный комбайн для поиска и квалификации клиентов на разработку, редизайн сайтов и AI-автоматизацию. Специально оптимизирован для рынков **Беларуси (РБ)**, **СНГ** и **международных рынков (США/Европа)**.

## 💥 Почему старая конверсия 1 к 100 превращается в 1 к 5–10?

Обычные парсеры собирают мусорную базу (городские стационарные телефоны, агрегаторы вроде relax.by/kufar.by вместо сайтов) и заставляют рассылать шаблонный спам.

**Lead Hunter Pro решает эту проблему на корню:**
1. **🇧🇾 Умная локализация Беларуси и СНГ:**
   - Распознает любые белорусские форматы номеров: `+375`, `8029...`, `029...`.
   - Автоматически отличает **мобильные номера (`📱 Моб.`)** от **городских офисных (`☎️ Гор.`)**.
   - Генерирует прямые ссылки в 1 клик для связи: **WhatsApp**, **Telegram**, **Viber** (по протоколу `viber://chat`).
   - Исключает белорусские каталоги (`onliner.by`, `kufar.by`, `relax.by`, `deal.by`, `tam.by`, `103.by`, `kartoteka.by` и др.) из официальных сайтов.
2. **🔍 Экспресс-аудит сайтов «на лету»:**
   - **📱 Проверка мобильной адаптации (viewport):** выявляет сайты, которые ломаются на смартфонах.
   - **💰 Детекция рекламных пикселей:** Яндекс.Метрика/Директ, Google Ads, Meta/FB Pixel, VK Пиксель, TikTok.
   - **🔥 Детекция «Слива бюджета»:** если компания крутит платную рекламу, но сайт без мобильной версии — лид получает высший приоритет `HIGH`. Владелец теряет деньги прямо сейчас и с радостью согласится на редизайн!
3. **💡 AI-генератор персональных питчей и скриптов звонка:**
   - Для каждого лида индивидуально составляется оффер под его боли (нет сайта / нет мобилки / крутят рекламу впустую).
   - 30-секундный скрипт звонка без "впаривания" (через бесплатный видео-разбор или концепт).
   - Встроенный алгоритмический генератор + опциональная интеграция с **Gemini API**.
4. **📡 Фоновый мониторинг Onliner & Бирж фриланса:**
   - Автоматический сбор заказов с **Onliner Услуги**, **Kwork**, **FL.ru**, **Freelancehunt**, **Telegram-каналов**.
   - Демон отслеживает новые заказы каждые несколько минут и мгновенно присылает уведомления в ваш **Telegram Bot**.

## 📊 Таблица квалификации лидов

| Бейдж в интерфейсе | Что означает | Ваша стратегия и оффер |
|---|---|---|
| **🔥 НЕТ САЙТА** | Активный бизнес с отзывами на картах, сайта нет вообще | Быстрый квиз или лендинг за 48 часов + гео-привязка карт. |
| **🔥 КРУТЯТ РЕКЛАМУ БЕЗ МОБИЛКИ** | Платят за Яндекс/VK/FB, но со смартфонов верстка сломана | **Самый горячий лид.** Аудит слива бюджета и мобильный редизайн. |
| **⚡ Соцсеть / Taplink** | Указан только Instagram, VK или Taplink | Упаковка соцсети в конверсионный веб-сайт с онлайн-записью. |
| **📱 НЕТ МОБИЛКИ** | Есть сайт на домене, но нет адаптива под смартфоны | Мобильная адаптация и перенос на современный стек. |
| **🛠️ Tilda / Wix** | Сайт собран на бесплатном конструкторе | Доработка конверсии, интеграция CRM и Telegram-уведомлений. |

## 🛠️ Запуск проекта

### 1. Веб-интерфейс (Рекомендуется)
```bash
.\venv\Scripts\python.exe main.py
```
или просто:
```bash
python main.py
```
Откройте в браузере: **`http://localhost:8080`**

```bash

```

## 🖥️ Вкладки и функции Веб-Интерфейса

- **Вкладка 1: 🗺️ Поиск лидов на картах:**
  - Выбор ниши: популярные ниши РБ/СНГ + прибыльные ниши США/Европы (`Roofing`, `HVAC`, `Plumbing`, `Dental` и др.).
  - Выбор городов в 1 клик: чипы всех областных центров Беларуси (`Минск`, `Брест`, `Гродно`, `Гомель`, `Витебск`, `Могилев`), городов-спутников и мегаполисов.
  - Источники: Яндекс Карты, 2ГИС, Google Maps или все одновременно.
  - Таблица лидов с бейджами: `📱 Моб.`, `☎️ Гор.`, `📱 НЕТ МОБИЛКИ!`, `💰 КРУТЯТ РЕКЛАМУ`.
  - Кнопка **«💡 AI-Питч»** у каждого лида: открывает модальное окно с готовым текстом для WhatsApp/Telegram и скриптом звонка. Кнопка «Копировать» в 1 клик!
  - Кнопки скачивания: **Excel (.xlsx)** и **CSV**.

- **Вкладка 2: 💼 Биржи фриланса & Telegram:**
  - Мгновенный парсинг горячих заказов с Onliner, Kwork, FL, Freelancehunt.
  - Прямые ссылки на отклики и фильтрация по бюджетам.

- **Вкладка 3: ⚙️ Настройки и Telegram Бот:**
  - Настройка Telegram Bot Token и Chat ID с кнопкой «🧪 Тест отправки».
  - Включение фонового авто-мониторинга с настраиваемым интервалом (по умолчанию каждые 3 минуты).
  - Ввод Gemini API Key для продвинутой AI-генерации текстов.

## 📁 Структура проекта

```
parser/
├── core/
│   ├── models.py           # Модели Lead/FreelanceOrder, парсер телефонов РБ/СНГ, мессенджеры

│   ├── ai_pitcher.py       # Генератор офферов для мессенджеров и скриптов звонка (30 сек)
│   ├── web_verifier.py     # Поиск сайтов в сети, фильтрация агрегаторов РБ/СНГ (.by, .бел)
│   ├── memory.py           # SQLite база leads_memory.db (защита от повторного сбора)
│   ├── exporter.py         # Экспорт в Excel и CSV со всеми новыми колонками и стилями
│   ├── notifier.py         # Управление settings.json и Telegram Bot API
│   └── niches.py           # Каталог маржинальных ниш и городов РБ/СНГ/США
├── scrapers/
│   ├── yandex.py           # Яндекс Карты (сбор номеров, раскрытие карточек)
│   ├── twogis.py           # 2ГИС (включая города Беларуси на 2gis.by)
│   ├── google.py           # Google Maps (глобальный парсер)
│   └── freelance/
│       ├── onliner.py      # Onliner Услуги (Беларусь)
│       ├── kwork.py        # Kwork
│       ├── fl.py           # FL.ru
│       ├── telegram.py     # Telegram каналы с заказами
│       ├── manager.py      # Агрегатор заказов
│       └── watcher.py      # Фоновый демон для Telegram-уведомлений
├── tests/
│   ├── test_classifier.py  # Тесты классификации сайтов
│   ├── test_exporter.py    # Тесты генерации Excel/CSV
│   ├── test_memory.py      # Тесты базы данных дедупликации
│   └── test_upgrade.py     # Тесты парсинга телефонов РБ, аудита и AI-питчей
├── web_ui.py               # Полнофункциональный браузерный Dashboard (порт 8080)
├── main.py                 # Точка запуска
├── pytest.ini              # Конфигурация тестов
└── settings.json           # Файл пользовательских настроек (токены, таймеры)
```
